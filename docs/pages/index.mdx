# AnkiBase

**Anki, Quizlet and AI, on your own server.** AnkiBase runs your real Anki collection in the browser, plays Quizlet sets in every Quizlet mode, and turns the words you're learning into AI-written stories with tap-to-translate.

## What's inside

| | |
|---|---|
| **Anki study** | Anki's own reviewer (exact order and daily limits). Every note type renders with its own HTML and CSS, plus audio, MathJax, cloze and type-in answers |
| **Quizlet** | Import sets from a link. Flashcards, Learn, Write, Test, Match, Blast and Blocks, with resumable sessions |
| **AI stories** | Claude, ChatGPT or Gemini write at your CEFR level using your words |
| **Reading** | Every word comes pre-annotated (dictionary form, meaning, grammar). Highlight a sentence to have it explained |
| **Search** | Dictionary entries plus "in your cards" matches across Anki and Quizlet |
| **Stats** | Anki-style statistics for Anki decks and Quizlet sets together |
| **Themes** | Nine built-in themes, custom colours, import/export |
| **Self-hosting** | One-line install, in-app updates, multiple users with permissions, a collection per profile, AnkiWeb or your own sync server |

See [Features](/features) for a tour with screenshots, or jump straight to [Getting Started](/getting-started).

## Stack

| Layer | Tech |
|---|---|
| Frontend | React 19, TypeScript, Vite, Tailwind CSS v4 |
| Backend | FastAPI + Uvicorn, SQLite |
| Anki engine | [anki-cli](https://github.com/Macro002/anki-cli): Anki's own engine, one service, a collection per profile |
| AI providers | Anthropic Claude, OpenAI, Google Gemini (optional, bring your own key) |
