# Configuration

## Environment Variables

The installer generates a `.env` file at `/opt/ankibase/backend/.env`. You can edit it manually if needed.

| Variable | Description | Default |
|---|---|---|
| `APP_SECRET_KEY` | Signs sessions and media links. Keep it secret | Auto-generated |
| `ANKIWEB_ENCRYPTION_KEY` | Fernet key that encrypts stored credentials | Auto-generated |
| `APP_PORT` | Backend listen port | First free port from `8000` |
| `CORS_ORIGINS` | Allowed browser origins | `http://localhost:<port>` |

Per-account data (stories, API keys) lives in `backend/data/<account>/`.

After editing, restart the service:

```bash
systemctl restart ankibase
```

## AI Providers

API keys are managed in the app under **Settings → AI** (or **AI settings** on the Story tab). Each provider has a default model, and you can switch models per story:

| Provider | Default model | Also available |
|---|---|---|
| Anthropic (Claude) | `claude-opus-5-5` | `claude-sonnet-5-5`, `claude-haiku-5-5` |
| OpenAI (ChatGPT) | `gpt-4o-mini` | `gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo` |
| Google Gemini | `gemini-2.0-flash` | `gemini-2.0-flash-lite`, `gemini-1.5-flash-8b`, `gemini-1.5-pro` |

AI is optional. Studying, Quizlet, search and stats all work without a key.

Keys are encrypted at rest using the `ENCRYPTION_KEY` from `.env`.

## Nginx

The installer can set up nginx automatically. If you need to configure it manually, here's the recommended config:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    client_max_body_size 500M;

    location / {
        proxy_pass         http://127.0.0.1:8000;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }
}
```

## Multi-user Setup

AnkiBase supports multiple users and multiple Anki accounts, each with its own collection.

- The first account created (id=1) is always the root admin and cannot be deleted or demoted.
- Admins can create users and assign account access via the **User Management** panel.
- Per-user permissions: `is_admin`, `can_add_containers` (create Anki accounts), and per-account access grants.

<Callout type="info">
  Accounts are cheap: they all share one Anki engine process, and a collection is only opened when it's used.
</Callout>

## AnkiWeb Sync

Each account can have its own AnkiWeb login, set with the **AnkiWeb** button in the header. Like Anki Desktop, only AnkiWeb's sync key is kept (in `/opt/ankibase/anki-data/anki-cli.json`, readable by root only), never your password.

Sync modes available:
- **Normal sync** — incremental, merges changes
- **Full upload** — overwrites AnkiWeb with local data
- **Full download** — overwrites local data with AnkiWeb
